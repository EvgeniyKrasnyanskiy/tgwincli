# Дорожная карта развития проекта (Roadmap)

В данном документе собраны предложения по развитию и оптимизации клиента Telegram, разбитые по функциональным направлениям и приоритетам.

---

## 🚀 Приоритет 1 (Высокий): Сеть, стабильность и интеграция прокси

### 1.1. Автоматический контроль процесса TG WS Proxy
- **Проблема:** Если программа `TgWsProxy_windows.exe` не запущена или случайно завершилась, клиент не может подключиться к Telegram.
- **Предложение:**
  - Добавить проверку запущенного процесса `TgWsProxy_windows.exe`.
  - Реализовать опцию в настройках: «Автоматически запускать TG WS Proxy при старте клиента», если он не запущен.
  - Реализовать контроль состояния процесса и перезапуск при зависании.

### 1.2. Мониторинг задержки (Ping) и качества связи
- **Предложение:**
  - Периодически измерять время отклика до серверов Telegram через `GetStateRequest`.
  - Отображать пинг в статус-баре рядом с индикатором сети (например: `● Подключен (42 мс)`).
  - При резком росте задержки или потере пакетов заранее предупреждать пользователя индикатором жёлтого цвета.

### 1.3. Автоматический Failover (резервный прокси)
- **Предложение:**
  - Возможность задать список из нескольких прокси (основной MTProto, запасной SOCKS5 / MTProto).
  - При 3 подряд неудачных попытках связи автоматически переключаться на резервный узел без ручного вмешательства.

## 🎨 Приоритет 2 (Средний): Интерфейс и пользовательский опыт (UI/UX)

### 2.1. Улучшение панели списка чатов
- **Поиск по диалогам:** поле быстрого поиска/фильтрации контактов над списком чатов.
- **Аватарки:** отображение миниатюр аватарок контактов рядом с именами.
- **Статусы контактов:** отображение статуса «В сети» / «Был недавно».
- **Индикатор набора текста:** анимация «печатает...» при наборе сообщения собеседником.

### 2.2. Продвинутая история сообщений
- **Пагинация (Lazy Loading):** подгрузка более старых сообщений при прокрутке вверх (сейчас загружаются только первые 50 сообщений).
- **Статусы сообщений:** иконки статуса отправки: одна галочка (доставлено на сервер), две галочки (прочитано).
- **Разделение сообщений по дням:** визуальные разделители с датами («Сегодня», «Вчера», «15 мая»).
- **Форматирование Markdown / HTML:** отображение жирного текста, курсива, цитат и блоков кода с подсветкой.

### 2.3. Всплывающие уведомления (Popup)
- **Настройка позиции уведомлений:** сохранение выбранной пользователем позиции (правый нижний угол, центр, верх).
- **Звуковые уведомления:** выбор пользовательского звукового файла (wav/mp3) вместо системного бипера.
- **Режим «Не беспокоить»:** переключатель в трее или интерфейсе для временного отключения всплывающих окон.

## 📁 Приоритет 3 (Средний): Работа с медиа и файлами

### 3.1. Предпросмотр медиа в чате
- Отображение миниатюр (thumbnails) для полученных и отправленных изображений прямо в окне чата, а не только текстового маркера `[📷 Фото]`.
- Возможность открыть изображение в полном размере по клику во встроенном легковесном просмотрщике.

### 3.2. Встроенный плеер голосовых сообщений
- Прослушивание голосовых (`.ogg` / `.opus`) и аудиосообщений прямо из интерфейса клиента с индикатором прогресса воспроизведения.

### 3.3. Визуальный прогресс передачи файлов
- Отображение реального прогресса скачивания и отправки файлов в процентах в статус-баре или рядом с сообщением.

---

## 🔒 Приоритет 4 (Низкий/Технический): Архитектура и безопасность

### 4.1. Локальный кэш диалогов и сообщений (SQLite)
- Сохранение истории сообщений в локальную базу данных SQLite.
- Позволит мгновенно открывать приложение и просматривать историю в офлайн-режиме до завершения сетевого подключения.

### 4.2. Безопасность сессии
- Возможность опционального шифрования файла сессии `client_session.session` локальным мастер-паролем для защиты от несанкционированного доступа при физическом доступе к ПК.

### 4.3. Автоматическое обновление приложения
- Проверка новых релизов на GitHub с уведомлением пользователя и возможностью автоматического обновления.
