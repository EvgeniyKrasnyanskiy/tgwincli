# План реализации: Настройки прокси и интеграция с TG WS Proxy

## Проблема
Клиент Telegram не может подключиться к сети. Причина:
В файле `.env` указан устаревший порт `10888` и старый ключ-секрет MTProto, тогда как локально запущенный процесс `TgWsProxy_windows.exe` слушает порт `1443` с секретом `99cbe1226ee5176cbb1a8e5501798321`.
Кроме того, в интерфейсе клиента отсутствует возможность просмотреть или изменить параметры прокси без ручного редактирования файлов конфигурации.
